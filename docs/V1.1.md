# SignalPilot V1.1 — production foundation

This release moves the prototype toward a real SaaS foundation.

## Included
- Email/password accounts with signed HTTP-only sessions
- User-owned businesses and persistent scan history
- Persistent opportunities
- Server-side dashboard
- Scan rate limiting
- SSRF-aware crawler with DNS checks, redirect validation and body-size limits
- Real robots.txt / sitemap probes
- Stripe subscription Checkout + signed webhook boundary
- API dashboard endpoint

## Setup
1. `npm install`
2. copy `.env.example` to `.env`
3. set `DATABASE_URL` and `AUTH_SECRET`
4. `npm run prisma:generate`
5. `npx prisma migrate dev --name v11`
6. `npm run typecheck`
7. `npm run build`

## Production hardening still recommended
Use a distributed rate limiter (Redis/Upstash), an egress proxy or isolated crawling worker, email verification/password reset, CSRF strategy for browser mutations, audit logs, background job infrastructure, and a real provider adapter for observed AI-search measurements.
