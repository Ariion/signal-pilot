# SignalPilot V1.5 — Control Center

## Objectif
Passer du diagnostic à l'action contrôlée sans dépendre d'une API IA.

## Nouveautés
- WordPress Control Center dans le cockpit entreprise.
- Connexion WordPress via Application Password.
- Liste et lecture des pages/articles depuis WordPress.
- Éditeur local titre/extrait/contenu.
- Création d'une action `wordpress_content` avec snapshot avant publication.
- Publication explicite uniquement après confirmation.
- Rollback depuis le snapshot.
- Revalidation de l'URL WordPress à chaque requête pour réduire l'exposition SSRF/DNS rebinding.
- Readiness Score utilisé dans le cockpit au lieu de présenter le score déterministe comme une mesure réelle d'une position dans une IA.

## Limites assumées
- L'éditeur ne publie jamais automatiquement.
- Le contenu n'est pas généré artificiellement si aucune API IA n'est configurée.
- La mesure de visibilité dans des moteurs propriétaires nécessite un fournisseur de données autorisé et n'est pas simulée.
